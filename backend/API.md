# Mithuru Mawatha API

The local base URL is `http://localhost:5000`. All request and response bodies use JSON.

Data is held in memory to keep the hackathon setup fast. The pre-seeded sample reports are restored whenever the server restarts, and changes made while the server is running are retained in memory.

---

## Report Fields

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Auto-generated by the API |
| `title` | string | Required; main summary title |
| `description` | string | Required; free-text description (at least 10 characters) |
| `category` | string | `Pothole`, `Streetlight`, `Drainage`, `Road Damage`, `Unsafe Area`, or `Other` |
| `location` | string | Required; readable place name |
| `severity` | string | `Low`, `Medium`, or `High`; defaults to `Medium` |
| `status` | string | `Open`, `In Progress`, or `Resolved` |
| `isAnonymous` | boolean | Defaults to `false` |
| `timeOfDay` | string or null | Optional; tag for unsafe-area reports (e.g. "Unsafe after dark") |
| `aiSummary` | string | AI-generated single-sentence summary |
| `aiUrgency` | string | `Low`, `Medium`, or `High` suggested by AI triage |
| `upvotes` | number | Count of community confirmations |
| `isVerified` | boolean | Admin verification flag (defaults to `false`) |
| `priority` | string | Admin manual priority override (`Low`, `Medium`, `High`) |
| `createdAt` | ISO date string | Auto-generated timestamp |

## Endpoints

### 1. AI Triage & Analysis
`POST /reports/analyze`

Analyzes free-text citizen descriptions and returns suggested classification and summary.

**Request Body:**
```json
{
  "description": "A deep pothole in the middle lane near Bambalapitiya bus stop forcing swerving at high speed."
}
```

**Successful Response (`200 OK`):**
```json
{
  "suggestedUrgency": "High",
  "suggestedCategory": "Pothole",
  "summary": "A deep pothole in the middle lane creates a swerving hazard for vehicles."
}
```

---

### 2. Platform Statistics
`GET /stats` or `GET /reports/stats`

Computes real-time statistics from the data store.

**Successful Response (`200 OK`):**
```json
{
  "totalReports": 8,
  "openCount": 4,
  "inProgressCount": 2,
  "resolvedCount": 2
}
```

---

### 3. Create a Report
`POST /reports`

**Request Body:**
```json
{
  "title": "Streetlight broken near school",
  "description": "The streetlight outside the school gate has not worked for three nights.",
  "category": "Streetlight",
  "location": "High Level Road, Nugegoda",
  "severity": "High",
  "isAnonymous": true,
  "aiSummary": "Broken lighting creates poor visibility outside a school.",
  "aiUrgency": "High"
}
```

**Successful Response (`201 Created`):**
```json
{
  "message": "Report created successfully",
  "report": {
    "id": "9",
    "title": "Streetlight broken near school",
    "description": "The streetlight outside the school gate has not worked for three nights.",
    "category": "Streetlight",
    "location": "High Level Road, Nugegoda",
    "severity": "High",
    "status": "Open",
    "isAnonymous": true,
    "timeOfDay": null,
    "aiSummary": "Broken lighting creates poor visibility outside a school.",
    "aiUrgency": "High",
    "upvotes": 0,
    "isVerified": false,
    "priority": "High",
    "createdAt": "2026-09-04T06:30:00.000Z"
  }
}
```

---

### 4. List and Filter Reports
`GET /reports`

**Query Parameters:**
- `category` — Filter by category (e.g. `Unsafe Area`, `Pothole`)
- `status` — Filter by status (`Open`, `In Progress`, `Resolved`)
- `search` — Keyword search on title or description

Example: `GET /reports?category=Unsafe%20Area&status=Open`

---

### 5. Get Single Report
`GET /reports/:id`

Returns report object matching the specified ID or `404 Not Found`.

---

### 6. Update Status
`PATCH /reports/:id/status`

**Request Body:**
```json
{
  "status": "In Progress"
}
```

---

### 7. Upvote / Confirm Report
`POST /reports/:id/upvote`

Increments report upvote count by 1.

---

### 8. Admin Verification
`PATCH /reports/:id/verify`

Marks a report as admin-verified (`isVerified: true`).

**Successful Response (`200 OK`):**
```json
{
  "message": "Report marked as verified",
  "report": { ... }
}
```

---

### 9. Admin Priority Override
`PATCH /reports/:id/priority`

**Request Body:**
```json
{
  "priority": "High"
}
```

**Successful Response (`200 OK`):**
```json
{
  "message": "Report priority updated successfully",
  "report": { ... }
}
```

## Environment Variables & Deployment

- `PORT` — Server listening port (default: `5000`)
- `GEMINI_API_KEY` — Google Gemini API key for live AI triage
- `OPENAI_API_KEY` — Optional alternative OpenAI API key

For Railway or Render:
- Start command: `npm start`
- Root directory: `backend`
