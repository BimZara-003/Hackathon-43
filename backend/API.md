# Mithuru Mawatha API

The local base URL is `http://localhost:5000`. All request and response bodies use JSON.

Data is held in memory to keep the hackathon setup fast. The eight sample reports are restored whenever the server restarts, and changes made while the server is running are not permanent.

## Report fields

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Generated by the API |
| `title` | string | Required |
| `description` | string | Required; at least 10 characters |
| `category` | string | `Pothole`, `Streetlight`, `Drainage`, `Road Damage`, `Unsafe Area`, or `Other` |
| `location` | string | Required; a readable place name |
| `severity` | string | `Low`, `Medium`, or `High`; defaults to `Medium` |
| `status` | string | New reports always start as `Open` |
| `isAnonymous` | boolean | Defaults to `false` |
| `timeOfDay` | string or null | Optional; useful for unsafe-area reports |
| `aiSummary` | string | Optional AI-generated summary |
| `aiUrgency` | string | `Low`, `Medium`, or `High`; defaults to severity |
| `upvotes` | number | New reports start at `0` |
| `createdAt` | ISO date string | Generated by the API |

## Create a report

`POST /reports`

Only `title`, `description`, `category`, and `location` are required.

Example request:

```json
{
  "title": "Streetlight broken near school",
  "description": "The streetlight outside the school gate has not worked for three nights.",
  "category": "Streetlight",
  "location": "High Level Road, Nugegoda",
  "severity": "High",
  "isAnonymous": true,
  "aiSummary": "Broken lighting creates poor visibility outside a school.",
  "aiUrgency": "High"
}
```

Successful response — `201 Created`:

```json
{
  "message": "Report created successfully",
  "report": {
    "id": "9",
    "title": "Streetlight broken near school",
    "description": "The streetlight outside the school gate has not worked for three nights.",
    "category": "Streetlight",
    "location": "High Level Road, Nugegoda",
    "severity": "High",
    "status": "Open",
    "isAnonymous": true,
    "timeOfDay": null,
    "aiSummary": "Broken lighting creates poor visibility outside a school.",
    "aiUrgency": "High",
    "upvotes": 0,
    "createdAt": "2026-09-04T06:30:00.000Z"
  }
}
```

Validation failure — `400 Bad Request`:

```json
{
  "error": "Description must be at least 10 characters"
}
```

## List and filter reports

`GET /reports`

Optional query parameters can be combined:

- `category` — exact category name, case-insensitive
- `status` — `Open`, `In Progress`, or `Resolved`, case-insensitive
- `search` — case-insensitive match against title or description

Example:

```text
GET /reports?category=Unsafe%20Area&status=Open&search=lighting
```

Successful response — `200 OK`:

```json
{
  "count": 1,
  "reports": [
    {
      "id": "4",
      "title": "Poorly lit isolated bus stop",
      "description": "The bus stop and nearby footpath are dark and feel isolated after evening hours.",
      "category": "Unsafe Area",
      "location": "Baseline Road, Dematagoda, Colombo 09",
      "severity": "High",
      "status": "Open",
      "isAnonymous": true,
      "timeOfDay": "Unsafe after dark",
      "aiSummary": "Poor lighting and isolation create a safety concern around the bus stop at night.",
      "aiUrgency": "High",
      "upvotes": 22,
      "createdAt": "2026-09-02T06:30:00.000Z"
    }
  ]
}
```

## Get one report

`GET /reports/:id`

Example: `GET /reports/1`

Successful response — `200 OK`:

```json
{
  "report": {
    "id": "1",
    "title": "Deep pothole near Bambalapitiya junction",
    "category": "Pothole",
    "status": "Open",
    "upvotes": 18
  }
}
```

The real response contains all report fields. If the ID does not exist, the API returns `404 Not Found`:

```json
{
  "error": "Report not found"
}
```

## Update a report's status

`PATCH /reports/:id/status`

Example request to `PATCH /reports/1/status`:

```json
{
  "status": "In Progress"
}
```

Successful response — `200 OK`:

```json
{
  "message": "Report status updated successfully",
  "report": {
    "id": "1",
    "title": "Deep pothole near Bambalapitiya junction",
    "status": "In Progress"
  }
}
```

The real response contains all report fields. An unsupported status returns `400 Bad Request`.

## Upvote a report

`POST /reports/:id/upvote`

No request body is required. Example: `POST /reports/1/upvote`.

Successful response — `200 OK`:

```json
{
  "message": "Upvote added successfully",
  "report": {
    "id": "1",
    "title": "Deep pothole near Bambalapitiya junction",
    "upvotes": 19
  }
}
```

The real response contains all report fields. A missing report returns `404 Not Found`.

## Run locally

```powershell
cd backend
npm install
npm run dev
```

For Render or Railway, use `npm start` as the start command. The server automatically reads the platform-provided `PORT` environment variable.
